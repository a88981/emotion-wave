追蹤線 · thread

使用說明 · how to use

核心原則

這是為情緒覺察設計的工具。核心紀律是：不在情緒裡做決定，等波完整走完。

情緒湧上來時，不需要思考、不需要分析。就是按一按、選一選，把當下標記下來，然後可以放下了。事後想反思再回來看。

什麼時候記錄

突然有情緒就記。不分早晚、不分大小事——只要身體有訊號、心裡有波動，就打開記錄。

不需要每天逼自己記固定次數。能持續才是重點。如果只能挑一個固定時間，建議睡前——一天結束時的波位最有訊息量。

聯想與事件

情緒升起時，不要急著問「我為什麼難過」——心智會編故事。試著只標記兩件事：

· 聯想：什麼自己浮上來了？一個名字、一個畫面、一個感覺（不需要解釋）

· 事件：當下發生了什麼事？看到、聽到、想到什麼具體的事情

累積一週後，到「回顧」可以看到模式：哪些主題反覆出現？它們各自伴隨什麼波位？身體先說、心智後聯想，模式自己浮現——這比直接分析可靠太多。

追蹤線的用法

當某件事一直在心裡轉——可能是個決定、關係、選擇——為它開一條追蹤線。在記錄時綁定這條線，這筆紀錄就會累積到那條線。

追蹤線的「清晰度評估」會告訴你波走到哪了：
· 尚在波中——還沒走過完整高低
· 逐漸收斂——走過高低但仍變動
· 清晰浮現——完整走過且近期穩定

重要決定，至少等到「清晰浮現」再做。

純波動 vs 事件影響

不是每次低點都因為某件事。情緒本身有自己的節律——有時就是低，跟事件無關。

觀察方法：如果某次低點完全沒有聯想，那可能就是純粹的身體波動，不需要找原因。學會分辨這個，能避免心智製造不必要的故事。

Google 試算表同步 · 手把手教學

第一次設定 15 分鐘左右。跟著做就能順利。

1 建立試算表

打開 Google 試算表，建一個新的，名稱可以叫「情緒波」。

在第一列（第 1 行）填入這些欄位名稱（從 A 欄到 L 欄）：

時間 日期 時段 波位 情緒 emoji 事件 感受 身體訊息 其他身體 聯想 追蹤線

把整段複製、貼到 A1 儲存格——Google 會自動展開到 L1。

2 打開 Apps Script

試算表上方選單 擴充功能 → Apps Script，會打開一個新分頁。

把預設的 function myFunction()... 整段刪掉，貼上這段程式碼：

function doPost(e) { try { var data = JSON.parse(e.postData.contents); var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getActiveSheet(); // Helper: get or create threads sheet function getThreadsSheet() { var t = ss.getSheetByName('追蹤線'); if (!t) { t = ss.insertSheet('追蹤線'); t.appendRow(['id', '標題', '脈絡描述', '建立時間', '完結時間', '狀態']); } return t; } if (data.action === 'test') { return ContentService.createTextOutput(JSON.stringify({ status: 'ok', message: '連線成功' })).setMimeType(ContentService.MimeType.JSON); } if (data.action === 'read') { // Read entries var entries = []; var lastRow = sheet.getLastRow(); if (lastRow >= 2) { var values = sheet.getRange(2, 1, lastRow - 1, 12).getValues(); entries = values.map(function(row) { return { date: row[0] instanceof Date ? row[0].toISOString() : String(row[0] || ''), waveLabel: String(row[3] || ''), mood: String(row[4] || ''), event: String(row[6] || ''), feeling: String(row[7] || ''), body: String(row[8] || ''), bodyExtra: String(row[9] || ''), association: String(row[10] || ''), threadTitle: String(row[11] || '') }; }).filter(function(e) { return e.date && e.mood; }); } // Read threads var threads = []; var ts = ss.getSheetByName('追蹤線'); if (ts) { var tLast = ts.getLastRow(); if (tLast >= 2) { var tValues = ts.getRange(2, 1, tLast - 1, 6).getValues(); threads = tValues.map(function(row) { return { id: String(row[0] || ''), title: String(row[1] || ''), desc: String(row[2] || ''), createdAt: row[3] instanceof Date ? row[3].toISOString() : String(row[3] || ''), resolvedAt: row[4] instanceof Date ? row[4].toISOString() : String(row[4] || ''), resolved: String(row[5] || '') === '已完結' }; }).filter(function(t) { return t.id && t.title; }); } } return ContentService.createTextOutput(JSON.stringify({ status: 'ok', entries: entries, threads: threads })).setMimeType(ContentService.MimeType.JSON); } if (data.action === 'sync_threads') { // Replace all threads on the threads sheet var ts = getThreadsSheet(); var lastRow = ts.getLastRow(); if (lastRow >= 2) { ts.getRange(2, 1, lastRow - 1, 6).clearContent(); } var threads = data.threads || []; threads.forEach(function(t) { ts.appendRow([ t.id || '', t.title || '', t.desc || '', t.createdAt || '', t.resolvedAt || '', t.resolved ? '已完結' : '進行中' ]); }); return ContentService.createTextOutput(JSON.stringify({ status: 'ok', count: threads.length })).setMimeType(ContentService.MimeType.JSON); } if (data.action === 'add' || data.action === 'batch') { var entries = data.action === 'batch' ? data.entries : [data.entry]; entries.forEach(function(entry) { var d = new Date(entry.date); var dateStr = Utilities.formatDate(d, 'Asia/Taipei', 'yyyy-MM-dd'); var timeStr = Utilities.formatDate(d, 'Asia/Taipei', 'HH:mm'); var hour = d.getHours(); var period = hour < 6 ? '凌晨' : hour < 12 ? '上午' : hour < 18 ? '下午' : '晚上'; sheet.appendRow([ entry.date, dateStr, period + ' ' + timeStr, entry.waveLabel || '', entry.mood || '', entry.emoji || '', entry.event || '', entry.feeling || '', (entry.body || []).join('、'), entry.bodyExtra || '', entry.association || '', entry.threadTitle || '' ]); }); return ContentService.createTextOutput(JSON.stringify({ status: 'ok', count: entries.length })).setMimeType(ContentService.MimeType.JSON); } return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: 'Unknown action' })).setMimeType(ContentService.MimeType.JSON); } catch (err) { return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: err.toString() })).setMimeType(ContentService.MimeType.JSON); } }

按 儲存（💾 圖示），會要你取一個專案名稱，例如「情緒波同步」。

3 部署為 Web App

右上角藍色按鈕 部署 → 新增部署作業。

類型選齒輪 ⚙ → Web 應用程式。

「執行身分」選 我自己。

「具有存取權的使用者」選 任何人。

⚠ 別緊張，這只是讓 app 可以匿名寫入。網址只有你知道、別人拿不到。網址就像鑰匙，自己保管好就好。

點 部署，第一次會要授權——點允許，看到警告畫面點「進階」→「前往（不安全）」→「允許」。（Google 對自己寫的腳本會這樣警告，這是正常的。）

授權完會看到 網路應用程式 URL，複製這個網址。

4 回到情緒波 app 設定

回到這個 app 的「設定」分頁，把剛才的網址貼到 Web App 網址 欄位。

點 測試連線。看到綠色「連線成功」就代表搞定了。

打開 新紀錄自動同步 開關 → 按 儲存設定。

5 補同步歷史資料（如果有）

如果你在設定同步之前已經記錄過東西，按 同步全部歷史紀錄到試算表，會一次補上所有舊資料。

之後每次記下此刻，就會自動寫入試算表，不用做任何事。

✦ 用試算表能做什麼

· 備份：手機資料即使消失，試算表的紀錄都還在

· 圖表分析：用樞紐分析看一個月情緒分佈、波位次數

· 跨裝置查看：手機、電腦、平板都能看

· 給 AI 做更深入分析：下載 CSV 或選取資料 → 貼給 Claude

· 分享給治療師/伴侶：直接分享試算表權限，不用截圖
